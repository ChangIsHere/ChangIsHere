## Hi, I'm Chang 👋

CS student at UW–Madison interested in **AI agents, distributed systems, and software engineering**.

🔬 I'm currently leading **ARFA (Action Residual Fused Agent)**, a research project exploring **residual-guided reasoning control for terminal-based coding agents**. ARFA uses the gap between expected and actual execution outcomes to determine **when an agent actually needs to reason again**, with the goal of reducing unnecessary LLM calls while preserving reliable task execution.

🧪 Currently validating execution-residual signals on **InterCode Bash**, benchmarking lexical, embedding, structured, and hybrid residual methods before extending to full agent experiments and SWE-bench.
